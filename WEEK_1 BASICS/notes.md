# Week 01 Notes

## Variables

Variables are used to store data.

Example:

```python
name = "Karan"
age = 22
```

---

## Data Types

- int
- float
- str
- bool

---

## Input

```python
name = input("Enter Name: ")
```

---

## If-Else

```python
if age >= 18:
    print("Eligible")
else:
    print("Not Eligible")
```

---

## For Loop

```python
for i in range(5):
    print(i)
```

---

## While Loop

```python
i = 1
while i <= 5:
    print(i)
    i += 1
```

---

## Important Points

- Python uses indentation.
- Variables are dynamically typed.
- range() starts from 0 by default.
- while loop continues until the condition becomes False.
